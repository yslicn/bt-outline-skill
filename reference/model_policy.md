# 角色与模型路由

| 工作 | 默认执行 | 说明 |
|---|---|---|
| 编排、启动硬门、阶段推进、用户确认门 | 当前对话模型 | 少量高价值判断 |
| 信息基底解析（阶段01）、规划初稿（阶段02）、提纲初稿（阶段03） | 强推理模型（Claude 强档） | 拆分逻辑与五层质量高度依赖推理，不建议低成本模型起草 |
| Architect 独立评审（方法论门） | 隔离上下文 subagent（强推理模型） | 只读本阶段 JSON + agent 文件 + methodology；不得产出者自评 |
| 业务专家 Reviewer（内容门） | 隔离上下文 subagent | 业务真实性/术语/覆盖；高风险冲突升级当前对话模型 |
| MD、统计、引用完整性、状态门、HTML/docx 渲染 | Python（ig_runtime.py） | 禁止交给模型手工同步 |

## 路由纪律

- 模型不可用时可使用当前模型，但必须在 `project_state.json.runs[]` 记录实际模型（`log-run` 命令），不得降低质量门。
- 低成本模型只能承担"批量字段/局部修订/枚举"，不能主导拆分逻辑与五层结构设计。
- 每个阶段实际用什么模型都要写 `runs[]`：`stage_id / role / model / task`。
